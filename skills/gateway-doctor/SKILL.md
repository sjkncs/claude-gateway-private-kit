---
name: gateway-doctor
description: Diagnose an authorized Claude Code gateway setup without exposing credentials.
---

先核对官方客户端版本及 gateway 管理方提供的模型 ID。只报告环境变量是否存在，不输出其值、完整 URL 或凭据。查看 `/status`，区分配置存在、请求成功与工具实际调用成功。

遇到 401/403 时由用户或管理员检查授权，不修改登录状态文件或尝试绕过验证。遇到 429 时停止批量调用，按服务端重试时间处理。工具失败时核查 API 格式、流式响应和工具调用的兼容性；不要通过关闭权限提示来掩盖错误。

MCP 单独用 `/mcp` 检查，只在用户允许的测试目录进行无敏感数据的读写。不能将模型回复正常视作 MCP 验收通过。

输出版本、检查时间、各项通过/失败/未测状态及下一步。不要输出原始请求头、个人路径、会话或完整日志。任何云端或订阅功能以官方文档和实际权限为准。
